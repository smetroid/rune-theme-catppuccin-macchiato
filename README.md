# rune-theme-catppuccin-macchiato

Catppuccin Macchiato for Rune, with a few tweaks: teal `red`, burnt-orange `yellow`, dark `blue`, lavender `fuchsia`.

## Install

    pkg install github.com/smetroid/rune-theme-catppuccin-macchiato

Then `guitheme macchiato`, or set `gui.default_theme: macchiato` in your config.
